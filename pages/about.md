这是我的个人博客，从 WordPress + 宝塔迁移过来的纯静态站点。

## 这个站点是怎么来的

- 生成器：`build.py`，只用 Python 标准库，没有 Hexo / Hugo / Jekyll，也没有 Node 依赖
- 内容：`posts/` 目录里的 Markdown 文件
- 托管：任意静态托管都行（GitHub Pages、Cloudflare Pages、对象存储……）
